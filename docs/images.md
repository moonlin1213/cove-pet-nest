# 图片、持续蜕变与生活照片

猫、狗和蛋有打包的通用素材。其他普通宠物可导入透明六格图集，或通过图片服务生成初始模样。神秘蛋首次孵化、后续成长和生活照共用可恢复的本地任务队列。

## 配置图片服务

```sh
export PET_NEST_IMAGE_ENDPOINT='https://images.example.test/v1/images/generations'
export PET_NEST_IMAGE_MODEL='YOUR_IMAGE_MODEL'
export PET_NEST_IMAGE_KEY='YOUR_PRIVATE_KEY'
# v0.2.0：持续蜕变和生活照还需要支持参考图的编辑接口
export PET_NEST_IMAGE_EDIT_ENDPOINT='https://images.example.test/v1/images/edits'
```

`example.test` 是占位域名。两个 endpoint 都是完整接口地址，不得带 URL 凭据、查询参数或片段；不会从生成地址猜编辑地址，也不会切换 Provider。编辑接口使用同一组 model/key，因此应配置为同一服务。

初始模样和首次孵化使用 JSON 生成接口。持续蜕变和生活照使用 multipart 编辑接口，参考图以 `image[]` 上传；协议参考 [OpenAI 图片编辑文档](https://developers.openai.com/api/docs/guides/image-generation)。服务须接受相应参数并返回 `data[0].b64_json`，项目不下载返回 URL，也不保证任意兼容服务都支持这些能力。

模样为透明 1536×1024、3 列×2 行六格图集；照片为不透明 1536×1024 的单幅生活场景。输入经尺寸、文件上限、图集 alpha 检查后派生为 WebP，并移除 metadata。生活照最多四个参与宝宝，每份参考图至多 8 MiB，总计至多 16 MiB。

没有编辑配置时，新阶段和照片等待配置，不发送无参考图的替代请求。只查看相册不会触发生图。持续成长达到门槛后由 `serve` 自动排队；生活照需要网页点击并确认，或宿主明确调用照片接口。

## 持续成长

成长值和相处天数必须同时满足。天数按 `PET_NEST_TIMEZONE` 下跨越的本地日期计算；第一阶段从领养算起，此后从上一阶段实际成功启用算起。

| 宝宝 | 下一阶段所需总成长值 / 至少相处天数 |
| --- | --- |
| 普通宠物 | 40 / 7 天 → 100 / 14 天 → 220 / 21 天 |
| 神秘灵宠 | 首次孵化 12 / 2 天 → 40 / 7 天 → 100 / 14 天 → 220 / 21 天 |
| 上述阶段之后 | 从上次启用时的实际成长值再增加 120，并相处 30 天；可以继续成长 |

普通宠物和神秘灵宠都保留个体种子、上一阶段形象及已经出现的特征。新的外观描述按本阶段的结构化关系维度选择书页、流星、风铃、心形或叶芽主题，在额心、背侧、尾尖等位置逐步增加物种适合的特征；相关性格维度也会小幅变化。没有结构化信号时使用稳定的种子选择。这里使用有界主题规则，不会另行调用语言模型解读书名、电影情节或私人聊天。

每个阶段的描述一旦准备就冻结；重试不会换身份或重新选择特征。编辑请求携带上一阶段图集，要求保留原有身份、颜色和特征。真实图片是否准确继承形象仍取决于服务能力。只有合格图片成功保存后才推进阶段和相册；失败、未知结果、晚到的过期任务都不能覆盖当前外观。

## 生活照片

v0.2.0 之后成功发生的喂食、陪玩、摸摸会自动记为生活片刻。重复回执、已经吃饱、没有粮或尚未就绪均不制造成功照顾记录。宿主也可上报阅读、观看、听歌、探索和陪伴事件，最多包含四个宝宝。

事件保存发生时对应的外观引用。即使以后蜕变，再为旧片刻生成照片也会使用当时的样子。同一事件只有一个持久照片任务；失败后重试该任务，不因新 request_id 另建重复照片。照片是根据真实事件重绘的插画，不是现实摄影，也不会凭空补写未发生的经历。生成照片不扣粮、不增加成长。

## 外发范围、任务与费用

初始生成只发送通用画风、物种和冻结的外观描述。**参考编辑还会把宝宝的外观图集发给你所配置的图片服务**；生活照会发送参与宝宝当时的图集和有界事件类型。姓名、聊天正文、关系摘要、宿主原始事件 ID 和数据库不会进入图片请求。请按自己的意愿选择图片服务，个性化宠物图可能含有你自己的设计信息。

成长外观、生活照和玩具图每天合计最多提交三次，成长外观优先。每次提交都占当天一个名额，包括失败、结果未知和手动重试。实际收费由所选服务决定。升级时，老版本保留的尝试次数会计入该任务最后记录的日期，当天的剩余名额可能因此减少，次日按新一天计算。

- `reserved`：等待配置、名额或执行；`submitted`：请求已提交。
- `success`：图片已保存；外观任务同时启用阶段，照片任务仅收进相册。
- `failed`：明确拒绝或图片处理失败；`unknown`：发送后结果不确定。
- `superseded`：导入或外观变更使旧任务失效，不可再重试。

发送后崩溃会在 180 秒租约过期后标为 `unknown`，不会自动重发。失败可在网页手动继续；`unknown` 必须确认“上次可能已计费”。重复重试 request_id 不重复排队。普通宠物可在开始成长前导入初始模样，之后返回 `appearance_locked_after_growth`，避免破坏已经冻结的成长与照片引用；不支持导入覆盖神秘蛋的固定身份。

本版使用离线图片和模拟断线验证流程，没有发起付费生图。真实图像质量、角色一致性、Provider 兼容性和费用需在接入者所选服务上验收。
