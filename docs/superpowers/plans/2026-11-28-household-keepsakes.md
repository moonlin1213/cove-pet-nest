# 灵宠屋后台创作实施计划

> For agentic workers: use superpowers:executing-plans for native execution or superpowers:subagent-driven-development for delegated execution. Review each step against the approved design.

**Goal:** 新装和升级后的公开小屋都能配置、在后台创作并保存自己的玩具和纸条，给每只爬宠保留独立栖息地。

**Architecture:** 复用本机服务的会话、宿主事件、SQLite 事务、worker 和图片任务。新增的文字服务与配置属于单个数据目录。两种后台礼物共用素材选择和任务记录；栖息地可独立使用。

**Tech Stack:** Python、FastAPI、SQLite、Pillow、原生浏览器模块、现有离线更新启动器。

**Spec:** [已确认的设计](../specs/2026-11-28-household-keepsakes-design.md)

## Global Constraints

没有用户启用就不发起新增模型调用；测试只用虚构家庭和模拟服务。限定本机访问，沿用原数据和认证。只发布公开电脑端；旧挂件配对仍可用。

## Review Focus

- 两个用户的数据目录或服务交错启动，素材和密钥仍各归其主。
- 重启、两个 worker 并发或超时，已提交的任务不会自动重发。
- 仅接 MCP 照顾、没有聊天摘要时，指引准确显示可用的素材。
- 生图名额用尽、只启用纸条或模型归因不可靠时，不凭空送出礼物。
- 图形启动器直达配对页、端口有自定义或从老数据恢复时，配置入口、宠物与配对保持可用。

## 1. 工程 agent 引导和本机配置

- [ ] 在 tests/test_creation_setup.py 先验证新装与 0.3.2 数据的默认关闭、密钥不回显、持久化配置只属于当前小屋、重复诊断不进入正式队列。运行目标 pytest，记录失败。
- [ ] 在 src/cove_pet_nest/creation_setup.py 提供 load_settings、保存和只返回状态的接口。复用已有图片设置，按该小屋配置的文字端点、模型、密钥和每日上限独立工作。浏览器会话管理设置，宿主和挂件凭据无权读写密钥。
- [ ] 在 http.py、web/index.html、web/passport.html 和新配置页面接入引导、复制给工程 agent、离线测试与可选的真实试生成。明确费用、发出的信息、就绪状态和关闭方法。
- [ ] 在软件包中维护唯一的中文指南，图形 ZIP 从同一来源打包。测试自定义端口、缺项提示、状态回读、配置修改与旧式环境变量；提交配置与引导。

## 2. 可恢复的后台创作

- [ ] 在 tests/test_creation_worker.py 先验证两户隔离、持久时钟、一次申领、额度、关停和未知结果。构造固定时间、假文字/图片服务和两组互不相干的互动。
- [ ] 在 creation_worker.py、service.py 和 images/ 下接入现有后台循环。素材仅来自完成的互动和真实照顾；维护事件引用、候选宠物、预约机会、任务状态、确认重试和调用记录。文本响应按任务校验格式、来源和归因；图片服务只接收外观简述，模型输出仅按数据展示。
- [ ] 玩具初次及交付后随机 1～7 天，从 14 天素材选取。纸条查 7 天素材，小屋与宠物均满一天、每户每日一次机会、30% 概率、同宠至少间隔 72 小时。用可控时钟覆盖边界，不等真实天数。
- [ ] 图片任务使用统一每日名额及成长优先级；一张图验证四种形态并生成透明轻量资源。纸条可独立运行。测试在提交前、提交后、保存前重启及重复投递；提交后台逻辑。

## 3. 收藏物和栖息地

- [ ] 在 tests/test_keepsakes.py 和浏览器验收中先定义收纳、摆出拖动、四形切换、按宠记数与五秒冷却、纸条已读/收藏，以及蛇和蜥蜴布局互不覆盖。
- [ ] 用独立服务和会话路由保存玩具、纸条、栖息地；同一事务完成礼物与到达记录。布局只接受该户拥有的玩具和已有爬宠，校验主题、装饰、坐标及缩放。
- [ ] 从藤篮、纸条和爬宠名册进入对应页面。只引入经过核对的通用素材。桌面及窄屏测试操作与刷新恢复；扩展备份枚举并恢复所有新增资源；提交三套玩法。

## 4. 回归与发布

- [ ] 两个空白数据目录分别走配置、上报、重启后台、收取、摆放、收藏、编辑栖息地、备份与还原。核对素材隔离、调用次数、日志、无配置状态；不读取任何真实家庭数据库。
- [ ] 用真实图形包从隔离的 0.3.2 安装升级，核验原宠物 ID、凭据、配对、同步与普通养成功能。运行全量 Python 和浏览器测试。
- [ ] 按新增功能发布 0.4.0。构建并扫描 wheel、源码包、图形 ZIP 及内嵌资源，核对资产来源、图片元数据、私有标识和凭据。合并前比对远端基线；发布后回下载附件核对摘要，用回下载的包验收入口、配置和三套玩法，记录通过项和限制。
