# 公开版灵宠屋 · 惊喜玩具、宠物纸条和专属栖息地

## 用户体验

持续运行的电脑端小屋从这家人和陪伴 agent 的真实互动中创作。聊天窗口关闭后，小屋仍能从已收到的片段发现灵感。比如，虚构的测试家庭共读了一本讲灯塔的书，几天后可能在藤篮里收到一盏摇摇晃晃的毛绒灯塔。玩具的来历能追溯到那次共读。每家用户提供自己的服务配置，独立保管宠物、记录和作品。

## 生成方式

已选择小屋后台创作。另一种可行方式是由陪伴 agent 在对话当场写好，再由小屋延迟送达，配置更少，但关闭聊天后只能送出已经构思好的礼物。公开版沿用后台创作的体验。工程 agent 负责升级和引导配置，陪伴 agent 所在的宿主传入真实互动，小屋的后台文字服务负责构思玩具与写纸条，图片服务负责画玩具。

## 素材、任务和费用

- 沿用已有宿主认证、互动摘要、生活事件和照顾回执。宿主在互动实际完成后传入有界摘要、类别、时间和稳定事件 ID。照顾事件保留宠物、动作、照顾者和结果。重复上报只记一次。只提供 MCP 工具而尚未接通宿主事件的用户，可以从实际照顾记录产生纸条；以聊天或共读为灵感的玩具需接入相应事件。升级引导显示已接通的来源。
- 获得该家庭确认后才启用新增后台模型调用。复用可用的图片服务；文字模型可使用用户已有的兼容服务。把模型地址、名称、密钥和启用状态分开配置。界面、日志及工程 agent 的检查结果只显示配置状态。向文字服务发送筛选后的相关片段，给图片服务的输入限于玩具的外观简述。把互动和模型返回的文本当作数据。
- 沿用持久化任务、每日额度及未知结果处理。文字有独立的每日调用上限与开关；玩具图与已有图片任务共享额度，成长外观优先。持久化下次机会、素材引用和任务状态，重启后继续。已发出但无法确认结果的请求由用户决定是否重试，重复点击或并发 worker 不能产生重复礼物或收费请求。关闭新增玩法不影响原有养成、相册和挂件配对。

## 三套玩法

**玩具箱。** 初次启用和成功送达后持久化随机 1～7 天的等待时间，从最近两周真实互动抽取素材，参考近期玩具避免重复。文字模型产出玩具名、外观和来历；一次生图绘制同一玩具的四种形态，整理为透明轻量图并校验后交付。没有素材、图片配置或配额时保留等待状态。藤篮可打开，查看来历与形态，摆出、拖动、收回，选宝宝玩并记录每只宠物的玩耍次数；沿用五秒冷却。玩具到达的纸条关联实际送达记录。

**宠物纸条。** 复用本地玩法的资格与节奏：小屋和宠物都满一天后，每个小屋每天一次机会，命中率 30%，同一只宠物间隔至少 72 小时。依据最近七天的新互动与该宠物成功的照顾记录写短笺；支持小观察、亲昵、零食和涂鸦。校验引用的素材、参与者和动作，没有依据的内容不落库。可以查看、标已读和收藏；这些操作不会重新调用模型。

**专属栖息地。** 蛇和蜥蜴各有自己的布置，支持暖石、苔林主题，摆放躲避屋、石头、蕨类和已拥有的玩具。支持调整位置、缩放和移除装饰，所有修改按宠物 ID 保存；重开小屋可恢复。栖息地使用随包提供的通用素材，无需配置模型就能布置。

## 新装与升级时，工程 agent 怎么引导

1. 随图形更新 ZIP 和安装后的软件都提供同一份中文「给工程 agent 的升级接入指南」，README 和更新说明链接到它。更新器当前打开 /passport，需在该落地页和小屋首页都提供可复制的引导指令与配置入口；用户可把指令交给自己选择的工程 agent，指令中只有指南位置和任务说明。普通用户也能跟随页面完成。保留原来的启动、选宠和配对入口。
2. 指南首先核对公开版版本、原虚拟环境和原数据目录，沿用已有宠物、凭据、图片设置和配对。配置写入实际启动小屋会读取的本机持久位置，限定本机账户访问。明文密钥由用户在本机填写，工程 agent 只检查是否就绪。
3. 依次说明「文字服务」「图片服务」「互动来源」「允许后台创作」的用途，展示每项的可用、待配置或已关闭状态。告诉用户哪些摘要会发给自己选的服务、如何调整额度或关闭。升级本身不触发模型测试。可以仅先开纸条，图片服务就绪后再开玩具。
4. 提供一条显式标为测试的虚构互动和离线诊断，验证上报、去重、服务配置可见性及持久化。测试素材与正式礼物队列隔离。实际付费试生成单独说明费用，由用户主动触发。最后给出可读结果，能区分配置完成、尚无互动、等待随机生成和服务故障。

## 公开发布与验收

仅移植通用逻辑和逐项审过的通用素材。发布物排除个体画像、真实聊天、生成过的礼物与纸条、数据库、凭据、私有路径和账户标识。测试使用两个独立虚构家庭，核对素材、模型输入、生成物与栖息地互相隔离。

验收走两条正常入口：新装，以及从电脑端 0.3.2 用图形包原地升级。检查旧数据和配对、工程 agent 指引可达、缺服务或未开启时的页面、关闭聊天后的后台生成、虚构素材对应的玩具和纸条、玩耍和收藏、两只爬宠独立布置、重启恢复、备份还原所有新增图片、异常重试与限额。使用可控时钟和模拟服务完成发布验证，不调用维护者的私人服务。发布新版电脑端、图形更新 ZIP 和说明，用回下载的公开包复核。挂件固件不参与此次更新。
