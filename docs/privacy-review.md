# v0.2.0 隐私与验收记录

## 公开范围

公开项目有独立 Git 历史。未复制来源应用的私有历史、运行数据库、聊天、关系记录、个性化宠物图、API 密钥或配置。示例、升级夹具和网页截图均来自隔离的虚构实例；角色固定为 user/assistant。新增功能直接在独立开源实现中完成，没有读取个人运行数据来制作演示。

公开版附带小屋、猫、狗、蛋，以及藤篮、纸心和五项栖息地通用 WebP。来源与 SHA-256 见素材清单，metadata 经过检查；未打包第三方字体。上游 MIT 声明保留。公开 GitHub 地址是接入说明需要的公开标识，提交使用通用贡献者身份。

## 数据流

用量接口只接收计数和长度，不接收聊天原文。关系摘要保存在用户本地，普通状态与 MCP 不返回它。启用后台创作时，小屋会把选中的近期摘要或其他合格素材交给用户配置的文字服务。新增生活事件仅接受有界类型、时间、事件 ID 和宝宝 ID；不接受任意故事、姓名或聊天字段。关系维度用于规则化成长主题，不额外调用语言模型。

参考图编辑会把宝宝当前或事件当时的图集发送给接入者自己配置的图片服务。图片描述不含姓名、关系摘要、聊天正文或宿主事件 ID。个性化宠物图本身也会外发，接入者需自行选择合适的服务。

读取相册不排队图片；生活照需明确请求。真实照顾成功才产生来源，重复回执和失败照顾不会伪造经历。同一事件只有一个照片任务。未知图片结果不会自动重试，需确认可能已经计费。

## 验证证据与边界

v0.2.0 在 Python 3.13、macOS ARM64 验证，45 项测试覆盖原有换粮/照顾/认证行为，以及双门槛成长、累积外观描述、旧图保留、过期结果防覆盖、照片去重、多人参考图快照、任务名额并发、失败重试、真实 multipart 请求结构、HTTP 与 MCP 相册、备份恢复。HTTP 图片传输使用 MockTransport，流程图片使用离线素材，未发起付费请求。

另用实际安装的 v0.1.0 生成隔离数据库，再用 v0.2.0 启动：宠物、粮仓、成长、六维性格、已孵化外观与原回执保留，新增历史补档且旧孵化日期明确为估计值。该检查不使用私人生产数据。

实际 v0.2.0 wheel 从 sdist 构建后，在独立虚拟环境安装，从源码目录之外验证 HTTP、四个真实 stdio MCP 工具、换粮去重、离线首次孵化、带参考图的后续成长、生活照去重和相册备份恢复。

Chrome 1280×800 与 390×844 浏览器检查涵盖相册翻页、阶段画像和生活照放大、照片请求与持久任务、无横向溢出；原小屋领养、喂食、刷新持久化和已饱不扣粮也有回归检查。测试屏幕尺寸不等于真实手机验收。

发行前对 wheel/sdist 的文件清单、凭据模式、用户绝对路径、运行文件排除、图片 metadata，以及准备推送的 Git 对象和通用提交者身份进行检查。扫描器不输出命中内容。v0.1.0 曾做独立代码评审；v0.2.0 以上证据来自当前实现和检查，不声称本版经过独立审计。

尚未验收真实图片 Provider 的角色继承、实际图片质量与费用，也未完成真实手机、Windows/Linux 或第三方 AI 应用兼容性验证。模式扫描和离线测试都不代替这些验收。

## 分享与恢复

用户数据目录中的凭据、数据库、图片、关系摘要、照顾记录、照片和备份都是私有内容，不得上传到源码仓库或发行包。新增历史图片与冻结参考图同样属于用户数据。公开发行使用文件准入与包内扫描，不直接压缩带运行状态的开发目录。

升级前先备份，停止旧网页服务和 MCP，再让新版沿用数据目录。恢复使用新的空目录与重新生成的凭据。完整步骤见 [升级说明](upgrade-v0.2.md) 与 [备份说明](backup.md)。
