# 最小核心版隐私与验收记录

此记录描述本地候选，不表示已经公开发布或完成真实图片 Provider 验收。

## 隐私边界

从空目录建立独立 Git 历史。未复制原仓库历史、运行数据库、聊天、关系记录、个性化宠物图、API 密钥或私人配置。示例与测试仅使用虚构资料。源码没有固定私人用户/AI 身份，公开角色为 user/assistant。

只准入四项通用 starter WebP：小屋背景、猫、狗、蛋图集，逐项检查外观、EXIF 和 SHA-256。README 的网页预览来自隔离虚构测试实例，并检查图片 metadata。未打包第三方字体。上游 MIT 版权声明保留，不作为私人身份数据删除。

后端用量接口只接收计数和长度，不接收聊天正文。关系摘要留在本地数据库，普通状态和 MCP 不返回它；图片请求不包含摘要、姓名或原始证据。配置与数据库路径不在 HTTP 状态或 doctor 输出中返回。

通过实际 wheel/sdist 的凭据模式、用户绝对路径、运行文件排除、图片 metadata 检查；发行文件清单单独审阅，本地拒绝名单不提交到仓库。扫描器只报告相对文件位置和类别，不输出命中值。模式扫描不能证明不存在任何形式的隐私；它与文件准入、示例来源检查、素材查看和独立代码评审共同构成交付证据。

## 验证范围

Python 3.13、macOS ARM64 本机验证，30 项测试通过：SQLite 状态/并发照顾、换粮余数/阶梯/去重/修订、关系与孵化描述、图片任务断线/unknown/重试、HTTP 身份/Origin/验证错误脱敏、官方 MCP 客户端 stdio 初始化与真实工具调用、备份哈希与恢复、素材资源加载。

实际 wheel 在另一干净虚拟环境安装，从源码目录之外运行，通过 HTTP 领养/照顾/换粮去重、真实 stdio MCP 三个工具调用、关系信号到首次孵化的离线完整流程；通用素材随安装包加载正常。

Chrome 实际网页验收：1280×800 与 390×844，领养猫/狗、喂食回执、刷新持久化、已饱不扣粮、无横向溢出；截图使用独立虚构测试实例。暂未在真实手机、Windows/Linux 或第三方 AI 应用中验收，不将这些环境列为已验证。

图片生成使用离线图集与断线传输测试；真实图片服务、生成图质量与费用尚未验证。其他普通种类的实际生成与神秘蛋的真实生成，必须由接入者配置服务后验收。初版只支持 b64_json 生成返回，透明六格图集不合格时会保留失败提示。

独立代码评审发现的导入图集覆盖问题已修复：导入终结排队任务，晚到成功/失败/未知结果均不能覆盖它，且旧任务不可再重试。宿主 HTTP 状态、领养、照顾接口另有认证隔离、固定 assistant 身份与幂等回归验证。已补强 JSON 凭据字段扫描，并明确跨日乱序事件的记账契约。

## 运行与分享

data_dir 中的 credentials.json、browser-url.txt、数据库、图片与备份是接入者私有内容，不得分享。公开仓库由受检查的文件建立全新历史，使用通用提交者信息，不携带本机开发历史；公开 GitHub 仓库地址是接入文档需要的公开标识。发行包不包含 .git。后续每次打包重新运行 scripts/check_release.py，检查新增素材，并对准备推送的 Git 历史与提交者身份重新审查；不要直接压缩含运行数据的工作目录。
