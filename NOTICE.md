# Attribution and asset scope

The pet-care economics, visible-conversation contribution policy and fantasy-pet concept are adapted from Cove. The upstream MIT copyright notice is preserved in LICENSE.

This independent implementation contains no upstream runtime databases, conversations, credentials, private relationships or individualized pet images. The four bundled starter images are generic shared UI artwork directed for Cove, selected individually for this distribution. Their checksums and source category are recorded in `src/cove_pet_nest/assets/manifest.json`. No personal pet assets or source repository history are included.

No third-party fonts are bundled. Python and browser dependencies retain their own licenses.
