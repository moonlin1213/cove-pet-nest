# 给工程 agent 的小屋后台创作配置指南

适用于电脑端灵宠屋 0.4.0。请让用户在自己的电脑上完成私人配置。

## 首次安装电脑端灵宠屋

1. 先问用户是否已养过宠物。有旧小屋就使用下一节的原地升级流程。全新小屋使用 Python 3.11 或更新版本，请工程 agent 依项目 README 安装到独立虚拟环境，并将 PET_NEST_DATA_DIR 指向用户选好的新存档目录。[从零启动](https://github.com/moonlin1213/cove-pet-nest#从零启动)
2. 用同一环境运行 `cove-pet-nest serve --port 8767`。请用户自己在本机浏览器打开存档目录中 `browser-url.txt` 的完整网址，完成首次登录。这个网址含私人访问码，请保留在本机。
3. 在首页领养第一只宠物，点「后台创作设置」。以后每次启动都沿用同一环境、存档目录和端口。

## 升级到原来的小屋

1. 找到用户原先启动小屋的项目和虚拟环境，读取软件包版本。原来的存档目录含有 pets.sqlite3 和 credentials.json。确认用户看见熟悉的宠物和可用的挂件配对即可，凭据留在本机。
2. 关闭旧小屋再运行图形更新器，选择原环境和原数据目录。使用原有启动方式和端口。已安装公开挂件固件的用户可继续使用现有配对。
3. 更新器会打开本机的 /passport 页面。从这里或首页点「后台创作设置」，先登录原小屋。所有路径都相对于这个小屋的实际地址。更新后的新增后台创作默认关闭。

## 让用户核对四项

- **文字服务**构思玩具和纸条。请用户选择兼容 chat completions 的完整 POST 地址和模型名，自行在本机设置页填写服务密钥。已有的 PET_NEST_TEXT_ENDPOINT、PET_NEST_TEXT_MODEL、PET_NEST_TEXT_KEY 可沿用。远程服务使用 HTTPS。本机服务可以使用 HTTP，地址填 localhost、127.0.0.1 或 [::1]。文字和玩具图片都遵循这项设置。
- **图片服务**只在做玩具图时用到。优先沿用原来的 PET_NEST_IMAGE_ENDPOINT、PET_NEST_IMAGE_MODEL、PET_NEST_IMAGE_KEY。新增设置里的图片覆盖只影响后台玩具图。玩具与现有图片任务共用每日额度。
- **互动来源**由各家庭的宿主接入。宿主在互动实际完成后，通过已有的宿主认证向 POST /api/integration/relationship 提交稳定的 event_id、真实 occurred_at、简短 summary 和 signals，例如 reading。再次提交相同事件使用原 ID 和原内容。共同生活事件可走 POST /api/integration/life-events，小屋网页和 MCP 的成功照顾会留下照顾回执。只接 MCP 时可以使用照顾素材写纸条。惊喜玩具还要有宿主上报的互动摘要或共同生活事件。请向用户说明哪些摘要会交给其文字服务，玩具图只需发送筛选出的外观描述。
- **允许后台创作**由用户在本机勾选「宠物纸条」或「惊喜玩具」，调整每日文字请求限额并保存。原服务无需为新增功能重配。配置保存在当前数据目录。macOS 和 Linux 的本机配置文件仅对当前用户开放读写。Windows 会先用 DPAPI 将整个服务配置加密，绑定到当前用户。换电脑或 Windows 账户时，请在新环境里重新填写。请求可能计费；日期切换、超时或人工重试会影响实际费用。用户可以随时关闭新任务。

## 验证配置

1. 先使用「运行离线诊断」。它会在临时小屋里记录一条明确标记为虚构的读书片段，重新打开临时库并重复上报同一条，检查持久化和去重。诊断结束会显示当前小屋的配置状态。它不会调用文字或图片服务，也不会为正式小屋添加素材。
2. 引导用户完成一次正常互动或照顾，再查看「互动来源」是否显示已收到。首次接入时可能尚无记录。小屋继续运行时才会等待生成机会，关闭聊天窗口是可以的。玩具通常随机等待 1～7 天，纸条依赖符合条件的宠物和新素材。
3. 用户愿意验证真实服务时，可以另行点「试一次文字生成」，阅读费用提示并确认。它以固定虚构片段测试一次文字服务，占用一次文字名额。不会新增一件正式玩具或宠物纸条。网络结果未知时先检查服务商账单或任务状态。继续确认重试可能再次计费。
4. 最后向用户报告文字服务、图片服务、已收到的来源、已开启的玩法与任务状态。请让用户在本机输入访问码和服务密钥，工程 agent 只读取页面上的配置状态及错误类别。

栖息地布置可以直接使用。备份和移动小屋时，请分别妥善保管模型设置与原登录凭据；跟随普通宠物数据备份迁往新电脑后，需要在新电脑重新确认自己的服务配置。
